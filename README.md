# Python Web Scraper & Streamlit Dashboard

A lightweight, automated web scraping tool and interactive dashboard built with Python, BeautifulSoup, and Streamlit.

## Features
- **Live Web Scraping:** Pulls real-time headlines and links from web sources.
- **Interactive Dashboard:** Built with Streamlit for a clean web interface without touching the terminal.
- **Data Export:** Automatically formats and exports extracted data into a downloadable CSV spreadsheet (`scraped_output.csv`).

## Built With
- Python 3
- Requests & BeautifulSoup4 (Web Scraping)
- Pandas (Data Processing)
- Streamlit (Web App Interface)
